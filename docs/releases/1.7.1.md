# Tellonce 1.7.1

Background memory recording is now enabled by default in Claude Code, Codex and Copilot. User-prompt hooks enqueue work without blocking the current conversation; a detached worker sends redacted user input to the platform CLI model to identify reusable corrections.

## Defaults and upgrades

- A missing configuration file or missing `memory_upsert_enabled` setting now means recording is enabled. This also applies to upgrades without an explicit setting.
- Existing explicit opt-out remains respected. Run `python <plugin>/lib/memory_upsert.py disable-hooks` to turn recording off, or set `PT_MEMORY_UPSERT_ENABLED=0`. Codex uses the equivalent `shared_lib/memory_upsert.py` entry.
- Environment overrides retain their existing precedence: `PT_MEMORY_UPSERT_ENABLED`, then `B5_MEMORY_UPSERT_ENABLED`, then the saved configuration. An existing unreadable configuration remains disabled.
- Hook status, Copilot status/dashboard, installation messages and platform skill instructions reflect the new default.
- Hard blocking and the separate shadow judge remain opt-in. Local retrieval does not require a model call.

Isolated experiment hosts retain their explicit learning and frozen-test controls. This release does not change running experiments or import personal memories into experiment libraries. The immutable v1.7.0 tag retains its original defaults.

All plugin and marketplace versions are 1.7.1. Copilot bootstrap and uninstall instructions point to v1.7.1; bootstrap checksums are listed in both Copilot READMEs. Update through the existing platform installation path and start a new session to load the new package.

## Validation

Regression checks cover defaults and explicit opt-out across all three shared-core variants, background hook queueing, status reporting and the existing isolated-runtime behavior. Release validation also checks version consistency, immutable download references, bootstrap checksums and shared-core parity. Real-model semantic checks and installation into personal environments are not part of this release validation; remote CI results are checked after publication.
