# Tellonce 1.8.1

This release makes everyday use lighter. Learning, rule format and the experiment APIs from 1.8.0 are unchanged.

## Lighter background learning

- Background learning now calls a small model through the CLI you are already logged into: Haiku on Claude Code and `gpt-6-luna` with low reasoning on Codex. Copilot keeps its default model because the small-model name could not be verified.
- Claude Code calls use a short system prompt with no tools, MCP servers, slash commands or session persistence. A typical signal check went from about 18k input tokens to about 430.
- If a CLI rejects these options or the small model is not available, the call is retried once with the previous plain invocation. Timeouts and a missing CLI are not retried.
- An explicit `PT_MEMORY_UPSERT_MODEL` still wins. `PT_MEMORY_UPSERT_REASONING` overrides the Codex reasoning effort.
- A model reply wrapped in a single Markdown code fence is unwrapped before JSON validation.

## Smaller per-turn injection

- The default `progressive_max` is now 20 instead of 50. Tier-1 rules are still pinned first and the rest rotate in across turns. Set `progressive_max` or `PT_PROGRESSIVE_MAX` to restore the old cap, or `0` for no cap.

## Legacy memory import

- Markdown files in the memory folder that are not rules, such as index or notes files, are skipped with a message instead of stopping the first import into SQLite.
- A file that looks like a rule but cannot be read still stops the import, as before. If that leaves the store empty and it has never held rules, retrieval falls back to the Markdown rules instead of injecting nothing.

## Skill description

- The skill is no longer described as required on every message. Learning and injection already run through hooks. The skill is now for viewing, correcting, deleting or reorganizing memory, recording by hand when automatic recording is off, and keeping the observation log when enforce mode is on.

## Compatibility and upgrade

All plugin manifests and marketplaces use 1.8.1. Copilot bootstrap and uninstall instructions point to the immutable v1.8.1 tag, and updated bootstrap checksums are listed in both Copilot READMEs. Update through the existing platform installation path and start a new session to load the new package.

## Validation

Before publication, the following passed locally:

- the full `checks` suite on Python 3.9 and 3.12, including new regression checks for the items above;
- the unified memory-upsert script;
- cross-variant shared-core parity;
- release metadata and bootstrap checksum validation;
- an end-to-end run with the real Claude Code CLI against a temporary memory folder: a non-rule index file was skipped, the existing rule was imported and injected, and a new preference was learned in the background by Haiku.

Remote CI results are checked after publication.
