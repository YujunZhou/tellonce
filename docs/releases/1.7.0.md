# Tellonce 1.7.0

This release moves opt-in automatic memory acquisition to user input and adds explicit APIs for isolated agent experiments. Default local retrieval and opt-in enforcement remain available through the existing platform integrations.

## User-facing changes

- Claude Code, Codex and Copilot automatic acquisition uses user-prompt events. Stop-time inspection does not initiate automatic learning.
- Signal detection and interpretation run in the background. Context is restricted to a captured window of the same conversation; unresolved references remain pending instead of injecting a clarification question into a later prompt.
- Fix mixed clear/pending updates, stale-plan replay, event deduplication and installation migration from the previous Stop hook registration.
- Keep automatic model-backed recording disabled until explicitly enabled. No personal seed memories are shipped or changed by this release.

## Host integration APIs

- Explicit library namespaces, correction-only learning policy, complete rules with conditions and exceptions, and bounded rule selection without private-library or whole-library fallback.
- Deterministic checks, model-backed checks and reminders, with positive/negative/not-applicable validation and stage-specific evidence requirements.
- Atomic publication of rules with their execution support, input-boundary version changes, training closeout and immutable test snapshots.
- Request-role/context attribution and one retry owner, including failed-request preservation rather than additional queue retries.

These are integration APIs in the shared core. A host must supply model transports, identities, execution observations and lifecycle calls. The default plugin retrieval path is not automatically replaced by the experimental selector, and this release does not claim that a full benchmark matrix or every platform's host integration has been validated.

## Compatibility and upgrade

All plugin manifests and marketplaces use 1.7.0. Copilot bootstrap URLs and embedded checkout refs point to the immutable v1.7.0 tag; their updated checksums are listed in the Copilot READMEs. Reinstall/update through the existing platform installation path to load the new package. An already-running session may still use its previous package until restarted.

Ordinary existing libraries keep their legacy explicit interfaces. Namespaced experiment libraries use the restricted correction policy and must not adopt an existing unrelated library. Ambiguous legacy records are retained for explicit inspection rather than automatically replayed without matching evidence/version.

## Validation scope

Linux shared-core regression checks, cross-variant byte parity, import/compile checks, shell syntax and package metadata are verified before publication. The real-model semantic fixture is opt-in and is not claimed as rerun for this release. CI separately checks the repository's supported OS/Python matrix; its observed outcome is recorded with the GitHub commit rather than assumed from local checks.

The initial release audit also found that the request-budget regression file was ignored and that installed skills still described automatic clarification injection. Both packaging omissions are corrected here; CI now runs the shipped background/runtime checks on POSIX platforms.
