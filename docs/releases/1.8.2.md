# Tellonce 1.8.2

This is a documentation fix for Codex. Code behavior is unchanged from 1.8.1.

## Codex skill entry

Codex reads its skill description from two files, depending on how it was installed:

- `codex/skills/tellonce/SKILL.md` for plugin installs;
- `codex/SKILL.md`, which `codex/install.sh` copies into `~/.codex/skills/tellonce/`.

These two files had drifted apart. The plugin copy still described `promote_candidate()` as the way to submit preferences and pointed the agent at the JSON projection, while the script copy was missing the guidance on splitting one correction into several rules. Both files now contain the same, current text, and `scripts/parity-check.sh` fails if they differ.

## Compatibility and upgrade

All plugin manifests and marketplaces use 1.8.2. Copilot bootstrap and uninstall instructions point to the immutable v1.8.2 tag, and updated bootstrap checksums are listed in both Copilot READMEs.

## Validation

Before publication, the full `checks` suite passed on Python 3.9 and 3.12, along with shared-core and Codex skill parity and release metadata and bootstrap checksum validation. Remote CI results are checked after publication.
